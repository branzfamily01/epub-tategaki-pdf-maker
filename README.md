# EPUB 縦書き PDF Maker

日本語 EPUB を、右開きの読みやすい縦書き PDF に変換する Windows 向けデスクトップアプリです。

## 特徴

- EPUB を 1 冊または複数冊まとめて選択
- EPUB の spine（本文順）を解析
- 縦書き・右開き想定の PDF を生成
- ルビを可能な範囲で保持
- 表紙画像を自動検出。適切な表紙がない場合はタイトルページを自動生成
- EPUB 内の挿絵を可能な範囲で保持
- B6 / A5 / A4 を選択
- ページ番号 ON / OFF
- バックグラウンド変換で GUI が固まりにくい
- PDF 完成後にページ数・破損を自動検査
- DRM / 暗号化された EPUB は解除しません
- 外部サーバーへのアップロードなし。PC 内だけで処理

## Windows で使う

### GitHub Actions で exe を作る（推奨）

1. このリポジトリを GitHub にアップロードします。
2. `Actions` タブを開きます。
3. `Build Windows EXE` を開きます。
4. `Run workflow` を押します。
5. 完了後、Artifacts の `EPUB-Tategaki-PDF-Maker-Windows` をダウンロードします。
6. ZIP を展開して `EPUB-Tategaki-PDF-Maker.exe` を起動します。

Python を自分でインストールして操作する必要はありません。

### 開発者向け：Python から起動

```bash
python -m pip install -r requirements.txt
python main.py
```

## 基本操作

1. `EPUBを選択` を押す
2. 変換したい EPUB を選ぶ（複数可）
3. 用紙サイズを選ぶ
4. `縦書きPDFを作成` を押す
5. 保存先を指定
6. 変換完了後、保存先を開く

## 標準組版

- 右から左へ列が進む縦書き
- 日本語縦書き用の句読点・括弧配置
- ルビ
- 段落字下げ
- 章改ページ
- ページ番号
- 表紙 / タイトルページ
- 挿絵

## 対応範囲

EPUB 2 / EPUB 3 の一般的なリフロー型 EPUB を主対象にしています。

出版社ごとに EPUB の内部構造や CSS は大きく異なるため、次のものは完全再現を保証しません。

- 固定レイアウト EPUB
- 漫画
- 数式を大量に含む書籍
- 複雑な表
- SVG を中心に組まれたページ
- 特殊な外字
- DRM / 暗号化 EPUB

本アプリは EPUB の CSS をそのまま PDF に印刷するのではなく、本文構造を読み取り、PDF 用に再組版します。そのため、元 EPUB とページ数は一致しません。

## 品質チェック

変換完了後に次を確認します。

- PDF が開けるか
- 1 ページ以上存在するか
- ファイルサイズが異常に小さくないか

将来版では、表紙・冒頭・25%・50%・75%・末尾ページの画像プレビューによる自動組版チェックを追加予定です。

## プライバシー

EPUB と生成 PDF は PC 内だけで処理します。アプリから書籍本文を外部サービスへ送信しません。

## 著作権

利用者が適法に扱える EPUB の変換を想定しています。著作権・利用規約に従って使用してください。本アプリには DRM を解除する機能はありません。
