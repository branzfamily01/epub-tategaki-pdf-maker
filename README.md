# EPUB 縦書き PDF Maker v2

日本語 EPUB を、右開きの読みやすい縦書き PDF に変換する Windows 向けデスクトップアプリです。

## v2 の特徴

- EPUB を1冊または複数冊まとめてキューへ追加
- フォルダー配下の EPUB を再帰的に一括追加
- 書名 / 著者を一覧表示し、変換前に上書き編集
- 文庫B6 / A5 / A4 に加えて Kindle Scribe / reMarkable / iPad 向けプリセット
- 出力ファイル名テンプレート `{title}` / `{author}`
- EPUB の spine（本文順）を解析
- 縦書き・右開き想定の PDF を生成
- ルビを可能な範囲で保持
- 表紙画像を自動検出。適切な表紙がない場合はタイトルページを自動生成
- EPUB 内の挿絵を可能な範囲で保持
- ページ番号 ON / OFF
- バックグラウンド変換
- 冊ごとの進捗・完了ページ数を表示
- 変換後に `conversion-report.csv` を自動生成
- 外部サーバーへのアップロードなし。PC 内だけで処理
- DRM / 暗号化された EPUB は解除しません

## 基本操作

1. `EPUBを追加` または `フォルダーから一括追加`
2. 必要なら書籍を選択して `メタデータ編集`
3. 閲覧端末や用途に合わせてプリセットを選択
4. 必要なら用紙・本文サイズ・表紙・ページ番号・出力名を変更
5. `キューをまとめて縦書きPDF化`
6. 完成後、保存先と `conversion-report.csv` を確認

## プリセット

- 文庫・小説（B6）
- 読みやすい大判（A5）
- 印刷・教材（A4）
- Kindle Scribe向け
- reMarkable向け
- iPad閲覧向け

プリセット選択後も用紙と本文サイズを手動調整できます。

## 参考にした設計原理

Epubor Ultimate 等の電子書籍コンバーターから、次の設計原理を参考にしています。

- 複数冊を一覧に貯めて一括処理する
- 変換前にメタデータを確認・修正できる
- 出力先と出力形式・端末用途を明確に選べる
- 進行状況を常に表示する
- 完成後の保存先へすぐアクセスできる

本アプリはそれらをそのまま複製せず、日本語縦書きPDFの再組版品質を中心に再設計しています。

## 方針

### 維持

- 日本語縦書きPDFの品質
- 右開き想定
- ルビ / 挿絵 / 表紙
- ローカル処理
- DRMフリーのファイルを対象

### 修正・拡張

- 単純なファイル選択から書籍キュー方式へ
- 用紙選択から用途・端末プリセットへ
- 変換完了だけでなくCSVレポートを残す
- EPUB内メタデータを変換前に確認・上書きできる

### 保留

MOBI / AZW3 / KFX / KEPUB / PDF などの入力形式は、形式ごとの再現品質・ライセンス・暗号化の扱いを検証してから追加します。

### 非採用

DRM解除・暗号化解除機能は実装しません。

## Windows で使う

GitHub Actions の `Build Windows EXE` が main 更新時に Windows 用 exe を生成します。

1. `Actions` タブを開く
2. 最新の `Build Windows EXE` を開く
3. Artifacts の `EPUB-Tategaki-PDF-Maker-Windows` をダウンロード
4. ZIP を展開
5. `EPUB-Tategaki-PDF-Maker.exe` を起動

Python を自分でインストールして操作する必要はありません。

## 対応範囲

EPUB 2 / EPUB 3 の一般的なリフロー型 EPUB を主対象にしています。

完全再現を保証しないもの：

- 固定レイアウト EPUB
- 漫画
- 数式を大量に含む書籍
- 複雑な表
- SVG 中心のページ
- 特殊な外字
- DRM / 暗号化 EPUB

元EPUBのCSSをそのまま印刷するのではなく、本文構造を読み取ってPDF用に再組版するため、元EPUBとページ数は一致しません。

## プライバシー

EPUB と生成 PDF は PC 内だけで処理します。書籍本文を外部サービスへ送信しません。
