# v2 upgrade plan

Reference: Epubor Ultimate feature principles (drag-and-drop, batch conversion, output presets, metadata editing, visible progress).

## Policy diff
- Maintain: local-only processing, vertical Japanese PDF quality, batch conversion, DRM-free scope.
- Modify: file selection becomes a persistent conversion queue with per-book metadata and status.
- Add: drag-and-drop (optional dependency), device/page presets, metadata editor, output naming template, auto-open output folder, conversion history/report.
- Hold: additional input formats (MOBI/AZW3/KFX/KEPUB/PDF) until format-specific quality and licensing are validated.
- Not adopted: DRM removal/decryption.
